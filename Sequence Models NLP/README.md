# 🚀 Sequence Models in NLP

This repository contains implementations and experiments related to **Sequence Models in Natural Language Processing (NLP)**. It covers fundamental and advanced deep learning architectures used for processing sequential data such as text.

---

## 📌 Overview

Sequence modeling is a core area of NLP where models learn patterns from ordered data (sentences, words, or tokens). This repo focuses on building and understanding models like:

- Recurrent Neural Networks (RNN)
- Long Short-Term Memory (LSTM)
- Gated Recurrent Units (GRU)
- Encoder-Decoder Architectures
- Attention Mechanism (if included)

---

## 🧠 Key Concepts Covered

- Word embeddings and sequence representation
- Handling variable-length sequences
- Vanishing/exploding gradient problem
- Bidirectional RNNs
- Sequence-to-sequence (Seq2Seq) learning
- Attention mechanism basics
