# Transformers - NLP Learning  🤖

This repository contains my learning journey and implementation work around **Transformer models in NLP (Natural Language Processing)** using PyTorch and Hugging Face ecosystem.

It includes concepts, experiments, and code implementations of key Transformer-based architectures and NLP tasks.

---

## 📌 Project Overview

Transformers are the backbone of modern NLP systems. This repository focuses on understanding and implementing:

- Self-Attention Mechanism
- Multi-Head Attention
- Positional Encoding
- Encoder-Decoder Architecture
- Layer Normalization in Transformers
- End-to-end Transformer workflow

The goal is to build a strong conceptual + practical foundation in deep learning for NLP.

---

## 🧠 Topics Covered

### 1. Attention Mechanism
Understanding how models focus on relevant parts of input sequences.

### 2. Self-Attention
Core idea behind Transformers where each token attends to every other token.

### 3. Multi-Head Attention
Improves model performance by learning multiple representation subspaces.

### 4. Positional Encoding
Adds sequence order information since Transformers do not use recurrence.

### 5. Layer Normalization
Stabilizes training and improves convergence in deep networks.

### 6. Transformer Architecture
Complete encoder-decoder structure used in modern NLP models.
